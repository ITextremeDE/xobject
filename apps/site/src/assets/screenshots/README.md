# Product screenshots

Actual xObject views from the fictional ITextreme workspace, captured in an isolated
Chromium session on 2026-11-09. Interface languages: English/German; appearances:
light/dark. Business contents are English demo data. No production records,
credentials or personal account data are present. John Doe is a fictional demo user.

`project` shows the Primary tree; `list` shows Projects; `contact` shows a Contact
person; `custom` shows a service-plan form; `journal` shows project history.
Images are unaltered browser captures (the list uses a shorter viewport crop).
Temporary localization choices were restored after capture. Regenerate from the
current optional demo fixture when relevant application views change.

Astro generates responsive WebP previews. Native image links expose full-size PNG
captures. These are product illustrations, not evidence of third-party client or
platform compatibility. The public social preview combines a project capture with
product text; it is not a separate application view.
