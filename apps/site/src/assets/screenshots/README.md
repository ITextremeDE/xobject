# Product screenshots

Actual xObject views of the fictional ITextreme workspace. Interface languages:
English/German; appearances: light/dark. Business contents remain English demo data.
No production records, credentials or personal account data are present. John Doe
is a fictional demo user.

All six views (`contact`, `conversion`, `project`, `list`, `custom` and `journal`)
were captured with Chromium on the local fictional demo on 2026-11-12 for
Community 1.3.0. Contact shows the current fixed core; conversion shows a completed
read-only preview before confirmation. No conversion was executed. Temporary
language preferences were restored and appearance was selected only inside the
capture browser. No record or dialog draft was saved. The list has a shorter
viewport crop.

Images are unaltered browser captures. Regenerate the affected view from the
current fictional demo when its relevant interface changes. An image is an
illustration, not evidence of a new release or platform acceptance.

Astro generates responsive WebP previews. Full-size links expose the original PNG
captures in the same-tab screenshot dialog. The public social preview combines a
project capture with product text; it is not a separate application view.
